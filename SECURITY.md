# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release. Verify suspected vulnerabilities against that release when possible.

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub Private Vulnerability Reporting or email [security@moonshot.ai](mailto:security@moonshot.ai):

- [Report a vulnerability on GitHub](https://github.com/MoonshotAI/kha/security/advisories/new)
- Email: [security@moonshot.ai](mailto:security@moonshot.ai)

Do not open a public issue for a suspected vulnerability. Include the affected version, reproduction steps, and potential impact to help maintainers assess the report.
